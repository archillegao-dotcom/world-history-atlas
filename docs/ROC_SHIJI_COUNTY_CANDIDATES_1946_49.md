# 史事纪要县域候选（民国三十五至三十八年）

只用国史馆出版品页上的绝版 PDF。政府资料开放授权。不改 1949-10-01 的中华人民共和国填色。显示文字写共军；来源标题保留原文。1945–1949 年中共接管记作沦陷。

正则是县名紧挨着「陷、失守、失陷、沦陷、陷落、攻陷、攻占、放弃、撤离、收复、克复」，中间可以只隔「遂、被、已、乃、又、再、於、相繼、先後」。县名是 1931 年 MCGD 县名。原句是 OCR。入库前对过原页。失陷格收到收复日；没有收复、后来落在既有整省里的，收到整省开始那天；两样都没有的不画。

印页：民国三十八年一月至六月这一册，正文印页按 PDF 减 8。印页一二八是 PDF 第136页，印页一四六是 PDF 第154页。
