# 史事纪要县域候选（民国三十三、三十四年）

只做这两年。全文 OCR 用国史馆绝版 PDF，竖排繁体。正则是县名紧挨着「陷、失守、失陷、攻占、侵占、放弃、收复、克复、接收」，再对一九三一年 MCGD 县名和别名（柳州＝马平、南宁＝邕宁、郑州＝郑县、郴州＝郴县、全州＝全县、宝庆＝邵阳）。原句入库前对过原页。失陷格收到收复日；没有收复、后来落在既有大块里的，收到那一块的开始；都没有则不画。长沙 1944-06-18、衡阳 1944-08-08、桂林 1944-11-09、柳州 1944-11-11 不改。
