# 史事纪要县域候选（民国三十一、三十二年）

只做这两年。目录没有民国三十一年十月至十二月，这一批没有这一册。PDF 是国史馆出版品页上的绝版全文，政府资料开放授权。正文是竖排扫描，没有文字层。全文 OCR 用直排繁体模型，原句入库前对过原页。正则是县名紧挨着陷、失守、失陷、陷落、沦陷、攻陷、进陷、攻占、侵占、放弃、收复、克复。书页是繁体，匹配用繁体。1931 年县名取 MCGD 的县名，县名和全称去掉「县」之后不一样的，两个都算。

失陷日是占领格的开始。后文有收复日的，收到收复日（不含当天）。没有收复、后来落在既有大块里的，收到那一块的开始。两样都没有，不画。同一件事两处日子不一致时，用较早且写「本日」的那一条，另一条写在注释里，标「史事纪要内记载不一」。原文写明日子的追述可以用。

博罗的收复日，印页三〇三（PDF 第311页）页眉二月四日，追述三十一日攻克博罗。印页二五八写的是一月三十日本日午后。史事纪要内记载不一。地图用一月三十日。印页三〇三又写博罗复陷，没有锁到一天，不另画。印页四一九写本周惠阳与博罗同时克复，博罗这一次也没有锁到一天。

惠阳一九三八年十月十五日那一格仍收到十一月十二日。这一格是一九四二年二月另一次。
